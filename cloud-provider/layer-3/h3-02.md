## H3-02 — Software Production Cost Can Decline With Reuse

> **Hypothesis:** Increasing blueprint coverage reduces the human effort required to produce a system.

### Summary

As more of a system's architecture and implementation is represented by reusable blueprint knowledge, less work must be recreated manually.

### Implementation

Blueprint Coverage ↑ → Manual Production ↓ → Verification Scope ↓ → Production Effort ↓.

### Value — Today

Defined portions of system production can already be generated rather than manually implemented.

### Value — Tomorrow

Increasing blueprint coverage progressively reduces the human effort required for system production.

### Evidence

[Generated Systems](../../evidence/generated-systems); [Production Measurements](../../evidence/measurements)

### Vision

Software organizations produce more capability with progressively less repetitive production effort.
