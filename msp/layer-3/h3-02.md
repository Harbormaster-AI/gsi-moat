## H3-02 — Lower Production Effort Can Increase the Number of Economically Viable Systems

> **Hypothesis:** As production effort declines, an MSP can pursue a larger population of new and modernization workloads that previously did not meet economic thresholds.

### Summary

Production efficiency can change the addressable workload population by reducing the effort required to create or modernize systems.

### Implementation

Lower Production Effort → Lower Cost to Produce → More Viable Projects → More Systems.

### Value — Today

Existing modernization and application initiatives can potentially be pursued with improved production economics.

### Value — Tomorrow

A larger set of customer systems can become economically viable candidates for creation or modernization.

### Evidence

[Production Measurements](../../evidence/production-measurements); [Modernization](../../evidence/modernization); [Generated Systems](../../evidence/generated-systems)

### Vision

Harbormaster expands the MSP's opportunity from competing for existing workloads to helping create additional workloads.
