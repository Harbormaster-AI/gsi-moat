## H3-03 — More Systems Can Create More Managed Workloads

> **Hypothesis:** An increase in economically viable system production can translate into an increase in workloads deployed into environments operated or managed by the MSP.

### Summary

New and modernized applications require infrastructure, deployment, monitoring, security and ongoing operational support. When Harbormaster makes more systems viable to produce, more opportunities can enter the managed estate.

### Implementation

More Economically Viable Systems → More Systems Produced → More Workloads Deployed → Larger Managed Estate.

### Value — Today

Generated systems can provide a pathway from application production into deployment and managed operation.

### Value — Tomorrow

Increasing production volume can create a larger population of workloads for the MSP to host and manage.

### Evidence

[Generated Systems](../../evidence/generated-systems); [Deployment](../../evidence/deployment); [Managed Workloads](../../evidence/managed-workloads)

### Vision

Harbormaster becomes a mechanism for expanding the MSP's managed workload base.
