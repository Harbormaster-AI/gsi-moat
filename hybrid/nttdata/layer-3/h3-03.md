## H3-03 — A Greater Proportion of Those Workloads Can Be Deployed Onto the Organization's Technology Platform

> **Hypothesis:** A technology provider that participates in software production can influence where an increasing portion of newly created and modernized workloads are deployed.

### Summary

When production capability is integrated with the technologies, architectures and deployment environments supported by a platform provider, software production can naturally lead into deployment on that platform.

### Implementation

Software Production → Platform-Compatible System → Deployment → Platform Workload.

### Value — Today

Systems can be generated for defined technology stacks and deployment environments.

### Value — Tomorrow

A broader production capability aligned with the platform can increase the number of workloads that naturally reach that platform.

### Evidence

[Blueprints](../../evidence/blueprints); [Generated Systems](../../evidence/generated-systems); [Deployment Artifacts](../../evidence/deployment-artifacts)

### Vision

Software production and platform adoption become connected stages of the same production lifecycle.
