## H1-05 — Enterprises Will Be Encouraged to Use the Services and Capabilities of the Platform That Creates the System

> **Hypothesis:** When a platform provides the capabilities used to produce an enterprise system, the production process can naturally encourage adoption of the platform's broader services and capabilities.

### Summary

Harbormaster can generate systems using defined technology, architecture and deployment blueprints. When those blueprints incorporate the capabilities of a platform provider, the resulting systems can naturally align with that provider's services and runtime environment.

### Implementation

Platform Capabilities → Production Blueprint → Generated System → Platform Deployment → Platform Usage.

### Value — Today

Systems can be generated using defined platform technologies and deployment capabilities.

### Value — Tomorrow

A growing blueprint continuum can make more platform capabilities available as part of the software-production process, increasing opportunities for adoption.

### Evidence

[Blueprints](../../evidence/blueprints); [Generated Systems](../../evidence/generated-systems); [Deployment Artifacts](../../evidence/deployment-artifacts)

### Vision

Software production becomes a mechanism through which platform capabilities are incorporated into the systems enterprises create and operate.
