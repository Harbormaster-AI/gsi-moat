## H3-04 — Increased Software Production Translates Into Measurable Incremental Resource Consumption

> **Hypothesis:** Additional software production resulting from lower production effort can be translated into measurable incremental consumption of compute, storage, networking and related platform resources.

### Summary

Each additional software-production event can result in an associated runtime workload whose resource requirements can be estimated and measured.

### Implementation

Additional Systems → Workload Profile → Resource Consumption → Platform Utilization.

### Value — Today

Workload categories can be associated with estimated resource-consumption profiles.

### Value — Tomorrow

Actual production and runtime data can increasingly establish the relationship between software-production volume and resource consumption.

### Evidence

[Workload Measurements](../../evidence/workload-measurements); [Consumption Models](../../evidence/consumption-models); [Generated Systems](../../evidence/generated-systems)

### Vision

Software production becomes a measurable leading indicator of future platform resource consumption.
