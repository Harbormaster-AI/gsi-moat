## H3-02 — New and Modernized Systems Create Additional Workloads

> **Hypothesis:** Increasing the number of new and modernized software systems produced results in additional applications and workloads that require computing resources to operate.

### Summary

Harbormaster's production efficiency can increase software output. Once those systems are deployed, they create corresponding runtime workloads.

### Implementation

More Software Production → More Systems Deployed → More Runtime Workloads.

### Value — Today

Generated systems provide a direct path from software production to deployable applications.

### Value — Tomorrow

Increasing software production can increase the number of workloads entering the runtime environment.

### Evidence

[Generated Systems](../../evidence/generated-systems/README.md); [Deployment Artifacts](../../evidence/deployment-artifacts); [Workload Measurements](../../evidence/workload-measurements)

### Vision

Improving the economics of software production expands the amount of software that ultimately requires operational computing resources.
