## H1-03 — Blueprint Coverage Can Progressively Reduce Enterprise Production Effort

> **Hypothesis:** As blueprint coverage expands across technologies, architectures and domains, an increasing portion of enterprise system production can be generated rather than manually constructed.

### Summary

Harbormaster separates the reusable production knowledge contained in blueprints from the project-specific information supplied through models, configuration and policies.

### Implementation

Blueprint Coverage → Greater Reuse → Greater Generated Scope → Less Manual Production Effort.

### Value — Today

Existing blueprints can eliminate substantial portions of repeated implementation work for applicable systems.

### Value — Tomorrow

A broader blueprint continuum increases the percentage of a system that can be generated from established production knowledge.

### Evidence

[Blueprints](../../evidence/blueprints); [Domain Models](../../evidence/domain-models); [Generated Systems](../../evidence/generated-systems)

### Vision

Enterprise production effort progressively shifts from recreating established capabilities toward defining what is unique about each system.
