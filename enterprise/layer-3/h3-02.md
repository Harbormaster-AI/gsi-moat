## H3-02 — Lower Production Effort Can Increase the Number of Economically Viable Systems

> **Hypothesis:** Reducing software-production effort can make applications and modernization initiatives economically viable that would otherwise be deferred, reduced or abandoned.

### Summary

The economics of software production determine which systems an enterprise can justify building or modernizing.

### Implementation

Lower Production Effort → Lower Cost / Greater Capacity → More Economically Viable Initiatives → More Systems Produced.

### Value — Today

Projects with substantial repeatable production requirements can require less engineering effort.

### Value — Tomorrow

The enterprise can potentially address a larger portion of its application portfolio within a given technology and engineering budget.

### Evidence

[Generated Systems](../../evidence/generated-systems); [Measurement Framework](../../evidence/measurements)

### Vision

Production economics become an enabler of portfolio strategy rather than a constraint that limits which systems can be built or modernized.
